# Event Sourcing Architecture

Event Sourcing is a software design pattern where an application stores every change as an event instead of saving only the latest data (traditional method).

Each event describes something that has happened, such as money being deposited or withdrawn. All events are stored in an Event Store in chronological order and They are never modified. The current state of the application is calculated by applying these events in order.

## Core Concepts:

**Commands:** Requests something to happen.

**Aggregate:** Validate request and Business Rules and determines whether the action is allowed

**Event:** It represents something that has successfully happened in the application.

**Event Store:** It is the storage system that maintains all the events generated by the application.

**Projections:** Convert events into useful information, such as the current bank balance.

This approach helps maintain complete history, track changes and investigate past activities.
